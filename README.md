🤖 ربات جرئت یا حقیقت گروهی تلگرام

یک ربات کامل و تعاملی برای بازی جرئت یا حقیقت در گروه‌های تلگرامی با سیستم نوبت‌دهی، رای‌گیری و مجازات‌های درون‌تلگرامی


✨ امکانات:

• شروع بازی با حداقل ۳ نفر و تایمر ۶۰ ثانیه‌ی پویا
• دریافت لیست سوالات از استارت‌کننده در هر دور
• انتخاب تصادفی پرسنده، پاسخ‌دهنده و سوال
• پاسخ‌دهی با ریپلای و شمارش لحظه‌ای
• تایمر ۶۰ ثانیه برای پاسخگویی
• سیستم رای‌گیری برای تعیین مجازات‌دهنده
• دکمه‌های شیشه‌ای تعاملی
• تایمر ۶ دقیقه‌ای برای انجام مجازات
• مدیریت کامل خطاها و پیام‌های غیرمجاز


🧠 تکنولوژی‌ها:

• Python 3.11
• aiogram 3 (بروزترین نسخه)
• APScheduler برای مدیریت تایمرها
• MemoryStorage (سریع و سبک)


🚀 نصب و اجرا:

1. کلون کردن ریپازیتوری
2. نصب وابستگی‌ها: pip install -r requirements.txt
3. قرار دادن توکن ربات در فایل bot.py
4. اجرا: python bot.py


📦 دپلوی در Railway:

• به‌صورت آماده برای Railway با Procfile
• نیازی به Webhook ندارد (Polling)
